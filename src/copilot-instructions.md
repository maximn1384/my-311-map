# Copilot Instructions: Power Apps Code App - 311 Map

## 1. Context and Architecture
* **Project Type:** Microsoft Power Apps Code App (React + TypeScript).
* **Environment:** This app will be deployed inside a Dynamics 365 Customer Service environment.
* **Goal:** Display Dynamics 365 Customer Service Cases (`incident` table) on a geographic map based on their latitude and longitude coordinates.

## 2. UI and Styling Rules
* **Component Library:** You MUST exclusively use `@fluentui/react-components` (Fluent UI v9). Do NOT use `@fluentui/react` (v8), Material UI, Tailwind (unless pre-configured in the starter template), or raw CSS.
* **Theming:** The app must respect the Power Apps theme context. Use standard Fluent UI v9 tokens (e.g., `tokens.colorBrandBackground`) for all custom styling via `makeStyles`.
* **Icons:** Use `@fluentui/react-icons`.

## 3. Data Integration (Dataverse)
* **No Direct APIs:** Do NOT write custom `fetch` or `axios` calls to the Dataverse Web API. 
* **Proxy Classes:** We will exclusively use the typed data services generated by the Power Platform CLI (`pac code add-data-source`). 
* **Table:** The primary table is `incident` (Cases). 
* **Mocking:** Use a `ServiceFactory` pattern. Always create a mock data service using realistic dummy Case data (including `title`, `ticketnumber`, `latitude`, `longitude`, and `statuscode`) so we can build the UI locally before connecting to the live Dataverse environment.

## 4. Mapping Requirements
* **Library:** When prompted to build the map, prioritize using `azure-maps-control` and `react-azure-maps`, or a stable React wrapper for Leaflet (e.g., `react-leaflet`). 
* **Performance:** The map must handle potentially hundreds of Case pins gracefully.

## 5. Coding Standards
* **Language:** Strict TypeScript. No `any` types. Define clear interfaces for all data models (e.g., `ICase`).
* **Components:** Use functional components and React Hooks (`useState`, `useEffect`, `useMemo`).
* **Pacing:** Do not build the entire app at once. Wait for my specific feature requests. If a step requires running a terminal command (like `npm install` or `pac code`), give me the exact command and wait for me to confirm it succeeded before writing the code that depends on it.
